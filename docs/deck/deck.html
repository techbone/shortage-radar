Agent workflow

Six steps, five roles, one rule: code checks the model

01

Ingest

Zetaris + World Model

Read the FDA feed. Replay every saved snapshot.

02

Diff

World Model

What changed since the last update, with dated history.

03

Match

Zetaris · Scout · H-MEM

Join stock and FDA status. Screen the rows. Set aside what is handled.

04

Alternatives

Planner · Nemotron

Choose what to cover. Find same-strength products from other makers.

05

Brief

Writer · Nemotron

Write one item at a time, citing evidence ids.

06

Critique

Critic · plain code

Reject any claim its evidence does not back.

When the Critic rejects a draft

The Writer gets a fresh prompt with the reasons, up to twice. Still wrong? That item becomes plain, deterministic text, labelled as such.

Bounded by design

5-minute run budget, timeouts on every call, two model calls at a time. If Zetaris or Nightshift is unreachable, the run falls back to a recorded replay and says so.

How Zetaris is used

Two sources, one statement, every number traceable

-- hospital Postgres (JDBC) joined with the FDA feed (REST)
SELECT f.ndc, f.generic_name,
       i.on_hand_units, i.daily_usage_units,
       s.availability AS fda_availability
FROM northwind_pg.formulary_item f
JOIN northwind_pg.inventory i ON i.ndc = f.ndc
LEFT JOIN fda.shortages s
  ON s.package_ndc = f.ndc
 AND s.status <> 'To Be Discontinued'

Why it can be trusted

Every sentence has a receipt, and a checker that is not a model

The Critic rejects a draft when:

  • the recommended NDC is not a same-concentration swap
  • it does not cite its own alternate’s record
  • a cited evidence id does not exist
  • days on hand do not match the stock data
  • it names a cause the FDA note does not state
  • it predicts a shortage

Caught in a live run: the Writer cited another drug’s alternate (alt:76329-1912-1) on sufentanil. The Critic sent it back; the retry was clean.

What was unique

Sponsor technology doing the work, and a result we were willing to throw away

Remove any sponsor, the flow stops

No Zetaris: no join of private stock and public feed. No World Model: no “what changed”. No H-MEM: handled items re-alert daily. No Scout: planted text reaches the model. No Nemotron: no plan, no write-ups.

We tested our first idea and dropped it

Do recalls predict shortages? Over 142 shortages, they were less common before one (0.7–0.9× baseline). So the agent never forecasts. It reports exposure, runway and swaps.

A swap means the same strength

The obvious query offered 10 mg/mL for 20 mg/mL and a premixed drip for a vial. Strengths are parsed to per-mL; combinations and preservative mismatches go to pharmacist review.

The checker is code

A second model agreeing with the first proves little. A function that recomputes the NDC, the citation and the day count cannot be talked into agreeing.

Honest limits and what is next

What it does not do yet

Limits, stated plainly

  • The hospital is fictional: real NDCs, invented stock. No patient data.
  • Scout is pattern-based and covers the guard stage only.
  • Strengths are read from FDA presentation text. Anything it cannot parse goes to review, never to a swap.
  • The free NVIDIA endpoint has latency spikes. The adapter retries once; the Critic loop falls back to plain text.
  • Decision support only. The buyer confirms with the label and the wholesaler.

Next

  • Wholesaler availability and NADAC prices as more Zetaris sources.
  • A Nemotron safety model as Scout’s second, model-based layer.
  • ASHP and manufacturer notices beside the FDA list.
  • Daily brief by email, and multi-hospital tenancy.
  • Real-hospital pilot on read-only inventory exports.
